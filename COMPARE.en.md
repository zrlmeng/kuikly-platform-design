# ShouZhuan UI vs official KuiklyUI

[中文](./COMPARE.md) · **English**

> **ShouZhuan UI** (platform-design) is the enterprise business design system and plugin layer on Kuikly Compose.  
> Kuikly renders; ShouZhuan delivers the product UI.

## Comparison

| Dimension | Official KuiklyUI (engine) | ShouZhuan UI / platform-design (design system) |
|-----------|----------------------------|------------------------------|
| Role | Cross-platform render + Compose/DSL primitives | Enterprise components + tokens/themes + plugins |
| Brand | Tencent TDS / Kuikly | **守赚 / ShouZhuan** |
| Theming | Framework Material-like defaults | Office/play scenes, OEM brand, dark mode |
| Feedback | Build from primitives | Toast, alerts, overlay, popover, guide, result |
| Forms | Primitive fields | Pickers, cascader, calendar, uploader, rate |
| Nav / display | Tabs / Lazy lists | Steps, back-to-top, collapse, index bar, notice |
| Visual craft | Generic primitives | Neumorphic convex/concave + CTA glow |
| Plugins | Samples / community | Charts, sign board, markdown, media |
| Distribution | Framework deps | Maven enterprise artifacts |
| Experience | Official samples | Gallery deep-link + docs / web / APK |

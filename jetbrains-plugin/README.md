# ShouZhuan Kuikly Kit（JetBrains）

**薄 DX** IDE 插件源码（Android Studio / IntelliJ / DevEco 辅助）。

- Marketplace：https://plugins.jetbrains.com/plugin/34786-shouzhuan-kuikly-kit  
- License：**Apache-2.0**  
- 本仓**仅含本插件**源码（模板 / 坐标插入 / 页桩）。  
- **不含**守赚 UI（platform-design）业务实现；运行时仍走 Maven 二进制。

## 能力

- Live Templates：`sz-button` / `sz-list` / `sz-dialog`
- Tools → ShouZhuan Kuikly：插入 Maven / OHPM 坐标
- 新建公开 API 页桩（`SzPage.kt.ft`）

## 构建说明

本目录为 Marketplace 对应的可读源码树。本地可用 IntelliJ Platform Gradle Plugin 打包；已发布制品见 Marketplace。
